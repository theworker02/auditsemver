# auditsemver

Audit CSV/TSV semver tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/auditsemver/

## Install / run

```bash
git clone https://github.com/theworker02/auditsemver.git
cd auditsemver
node src/cli.js
node --test
```
